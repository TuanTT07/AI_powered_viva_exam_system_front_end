# Accessibility

## Baseline

Target WCAG-informed accessible interaction.

## Required

- semantic HTML,
- keyboard-operable controls,
- visible focus,
- labels for form controls,
- sufficient contrast,
- status not communicated by color alone,
- accessible error messages,
- meaningful button names.

## Viva Session

Realtime status changes should be understandable without relying only on animation.

Examples:
- Recording
- Transcribing
- AI is preparing a follow-up
- Connection lost
- Reconnected

Avoid aggressive announcements for rapidly changing partial transcripts.

## Media

Device check must clearly explain:
- permission denied,
- no device found,
- muted device,
- retry action.
