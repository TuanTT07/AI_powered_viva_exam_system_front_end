# UI Checklist

## Design
- [ ] Uses approved design tokens
- [ ] Uses existing shared components where possible
- [ ] No arbitrary spacing/radius/color values without reason
- [ ] Matches the approved Stitch reference
- [ ] Typography hierarchy is consistent

## States
- [ ] Default
- [ ] Loading
- [ ] Empty
- [ ] Error
- [ ] Disabled
- [ ] Success if applicable
- [ ] Permission denied if applicable

## Interaction
- [ ] Click/tap targets are usable
- [ ] Focus state is visible
- [ ] Keyboard navigation works where applicable
- [ ] Forms expose validation near the field
- [ ] Submit actions prevent duplicate submission

## Responsive
- [ ] Target desktop width verified
- [ ] Narrow viewport verified
- [ ] Long text does not break layout
- [ ] Table/list overflow is handled

## AIVES
- [ ] AI suggestions are labeled clearly
- [ ] Final lecturer decisions are distinct
- [ ] Sensitive information is role-appropriate
