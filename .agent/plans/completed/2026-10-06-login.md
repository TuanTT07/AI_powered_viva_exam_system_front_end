# Login Feature

## Goal

Implement the AIVES `/login` page with validated credential entry, session-bound authentication and role-safe navigation.

## Scope Delivered

- Reused the M1 route, session and shared primitive boundaries.
- Implemented email/password Login, session loading, validation, pending and failed-authentication states.
- Added a deterministic development-only adapter; production authentication never succeeds through it.
- Added role-safe return-path validation and Login/guard tests.

## Constraints Recorded

- Reference TD-01 is a live-only, unconfirmed Stitch node (`e96f0b09180449ef9c73749014bec0d2`); `raw/stitch/` has no Login export or screenshot.
- Real identity-provider/API contract remains TBD; no production endpoint, DTO, token or SSO behavior is invented.
- Remember-me is omitted because it is not an approved product requirement.
