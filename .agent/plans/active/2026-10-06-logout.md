# ExecPlan: Frontend logout

## Goal

Add safe local logout through the existing AuthAdapter and SessionProvider boundaries, with cache clearing and a shared authenticated-layout action.

## Steps

1. Extend every AuthAdapter with `signOut()` and make SessionProvider clear session and TanStack Query cache safely, including adapter failure.
2. Add one accessible pending Logout button to `WorkspaceLayout` so lecturer, student and admin layouts share behavior.
3. Add focused adapter/session/layout tests, update auth documentation and replace stale header copy.
4. Run typecheck/lint/tests/build, verify all roles in the browser, then commit and push `feature/logout`.

## Constraints

- No backend logout endpoint, JWT, refresh or revocation API is invented.
- No second auth store is introduced.
- Explicit logout uses replace navigation and clears all query cache.
