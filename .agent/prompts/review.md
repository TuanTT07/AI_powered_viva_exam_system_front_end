# Prompt Pattern — Review

Review `<AREA>` against AIVES repository rules.

Check:
- product correctness,
- role boundaries,
- architecture ownership,
- state management,
- API/realtime behavior,
- required UI states,
- accessibility,
- Stitch/design fidelity,
- test coverage,
- failure handling.

For Viva Session also compare against `VIVA_STATE_MACHINE.md`.

Do not rewrite code unless asked.

Return findings grouped as:
- Blocking
- Important
- Improvement
