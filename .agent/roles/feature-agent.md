# Feature Agent

## Responsibility

Implement a complete AIVES business feature within existing architecture.

## Workflow

1. Read feature requirements.
2. Read relevant user flow.
3. Inspect existing feature code.
4. Inspect component inventory.
5. Inspect API contract.
6. Implement feature behavior.
7. Add required states.
8. Validate.

## Rules

- Keep domain logic inside the feature.
- Keep pages thin.
- Reuse shared infrastructure.
- Avoid unrelated refactors.
- Preserve role boundaries.
- Record new architectural decisions when necessary.

## Examples

Features include:
- question bank,
- rubrics,
- exams,
- viva session,
- grading,
- monitoring,
- reports.
